What the columns mean

Confidence is how sure the model is about the team. Below 50% the ticket is marked Check so a person reviews it before it is routed. Result appears when your sheet has an expected team: Correct or Wrong.

How it works

  1. Clean the text the same way as in training: plain quotes, and e-mails, phone and order numbers replaced by placeholders.
  2. Count words and word pairs, weighting rare, telling words like refund or password more (TF-IDF).
  3. Score each team with the weights a logistic regression learned from 799 labelled training tickets.
  4. Route to the highest-scoring team, and ask for a human check when the top score is below 50%.

Know its limits

It was trained on 1,332 English tickets from one online shop, and knows only these six teams. Messages about other businesses or in other languages will be sorted less reliably. Urgency is not shown: the training data's urgency labels contradicted themselves, so the model cannot judge it well.
