# Ticket Classification and Routing

A web tool that sorts customer support tickets into six teams (billing, delivery, returns, product, account, other).
Upload a CSV with a `ticket` column, paste messages, or try the built-in example sheet. The model (TF-IDF + logistic regression, macro F1 0.85 on held-out test tickets) runs entirely in the browser, so no ticket data is sent anywhere.

Student capstone project, Master 2 DSBA, EDC Paris Business School.
